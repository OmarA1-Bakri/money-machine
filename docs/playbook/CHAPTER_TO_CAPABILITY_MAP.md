## Canonical classifications

- Side-effect classes: `NONE`, `EXTERNAL_READ`, `EXTERNAL_WRITE`, `EXTERNAL_SPEND`, `EXTERNAL_MESSAGE`.
- Retry classes: `SAFE`, `IDEMPOTENT`, `RECONCILE_FIRST`, `MANUAL_RESUME`, `NEVER`.
- Autonomy modes: `simulation`, `draft`, `live`; tests always use `simulation`.
- Any `UNCERTAIN_EXTERNAL_EFFECT` blocks ordinary retry until an adapter-specific reconciliation result is persisted.
